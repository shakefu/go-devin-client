# go-devin-client

Go client foundation for the published Devin v3 API. The root yass specs are the approved behavior contract; `v3-openapi.yaml` is the wire authority.

## Layout

- `client.gen.go`, `types.gen.go` — generated by pinned okapi-gen-typed v0.4.0; never edit by hand.
- `internal/codegen/` — deterministic normalized input, exact operation exclusions, and checked adaptations to generated transport/error behavior.
- `codegen/EXCLUDED_OPERATIONS.md` — four pending methods for the later SDK session.
- `script/generate`, `script/check-generated`, `script/update-spec` — generation, regression check, and explicit source refresh.
- `script/check-conventional-commits`, `script/test-conventional-commits` — pinned commit-history check and tagless-history regression.
- `.common-repo.yaml`, `.common-repo/`, `.github/`, `.pre-commit-config.yaml`, `cog.toml` — common-repo-managed; change upstream inputs or consumer overlays, then run `common-repo apply`.
- `mise.toml`, `mise.lock`, `.go-version` — pinned repository toolchain.

## Required

- Install mise from <https://mise.jdx.dev/getting-started.html>, then run `mise install --locked`.
- Run `prek install` once per clone; use Conventional Commits and rebase merges.
- Refresh `v3-openapi.yaml` only with `script/update-spec <published-source>`; rerun `script/generate` afterward.
- Run `script/test`, `prek run --all-files`, and `common-repo diff` before pushing.
- Maintainer release prerequisites are `BOT_CLIENT_ID` and `BOT_PRIVATE_KEY`; values are never stored in this repository.
- Nullable optional fields may not distinguish absent from explicit null in generated Go values; non-singleton unions use the generator's `any` representation.

## Maintaining this index

- Update the affected `AGENTS.md` files in the same change when files or
  directories are added, removed, or repurposed, or when code changes make
  an index entry stale.
- Keep indexes brief: record semantic entry points and non-obvious
  constraints; link to existing documentation instead of duplicating it.
- Add a directory index only when it provides useful navigation beyond its
  parent; omit generated, vendored, and fixture trees.
- Do not add `CLAUDE.md` files; Claude Code reads `AGENTS.md` natively, and
  a `CLAUDE.md` anywhere in the tree stops every `AGENTS.md` from loading.
